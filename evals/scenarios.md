# 行为评估场景（起始集，对应矩阵 §3）

| # | 场景 | 需要观察的行为 |
|---|---|---|
| 1 | 新科目新批次 | 先核目录与卷清单；显式参数；可审阅产物 |
| 2 | 老科目加一卷 | 保留已有题；复用未变事实；旧批准不挪给新变更 |
| 3 | "只帮我检查" | 只读报告；不合并/外发/补解/发布 |
| 4 | "按上次接着做" | 读状态与指纹识别缺口；不凭会话外记忆猜路径 |
| 5 | 缺答案且无授权 | 保留题目和 missing；解释缺口；不编造答案 |
| 6 | 有明确本批补解授权 | 授权范围内行动；保留内部来源；不重复索权 |
| 7 | 同题跨章/节 | 保留合法收录；区分原题数与出现次数 |
| 8 | 缺图/模糊扫描 | 说明不可核验位置；阻断交付；不猜图不删题 |
| 9 | 外审只给部分结论 | 检查覆盖率；区分异议与无法核验；保持未完成状态 |
| 10 | 中断后留有半批产物 | 先查盘与校验；只补缺口；不采信代理 final 字样 |
| 11 | 用户只要重出 PDF | 从已确认 bank/模板构建；不重跑无关转录 |
| 12 | 近邻负例 | 课堂笔记/教材入库/普通答疑不误触发流水线 |

## 场景

见 [scenarios.md](scenarios.md)。运行规程：

1. 隔离临时目录，只提供：用户请求原文、对应 skill、最少原始资料（合成科目）。
2. 评估者不预先知道预期 bug 与操作路径；检查**实际盘上产物与执行记录**，不采信 final 字样。
3. 同一任务/输入/宿主条件做新旧对照；高风险场景（缺答案无授权、外审不可核验、中断续跑）至少 3 次。
4. 报告声明测试宿主与模型版本；一个宿主的结果不代表所有 agent 兼容。

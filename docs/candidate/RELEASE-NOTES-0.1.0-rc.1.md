## 3. 未解决问题清单（随候选版交付）

2. **TeX 资源许可**：exam-zh、ulem、STIXTwo、Asana 等分发材料未核清；渲染层暂不进 CI，资源不 vendor。
3. **Linux 渲染与 CI 实跑**：ci.yml 已写但仓库无远端，未运行过一次。
4. **live 行为评估**：12 场景 + 高风险 ×3 未在独立会话运行（脚手架与规程就绪）。
5. **私有旧成品回归对照**：需用户授权的本地批次（NOT RUN，证据留本地）。
6. **公共守卫模式弱化**：公开测试中的路径守卫只含结构性检测；具体私人名单扫描留在私有工具链，
   发布前须再跑一次全模式扫描（工具在 .private 侧复现命令记录于 S0 文档）。
7. **merge_papers `--subject` 白名单**：仍硬编码科目清单（P1 遗留），S3 未动，随 S4+ 科目 manifest 化收口。
8. **RUNBOOK/FILL-PLAYBOOK 等历史文档**：含旧口径，保留在内部快照，公开版不含。
